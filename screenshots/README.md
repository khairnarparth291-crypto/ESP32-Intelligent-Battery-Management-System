# Project Screenshots

This directory documents the visual evidence collected during the
development and simulation of the **ESP32 Intelligent Battery Management System**.

The project uses ESP32, Wokwi simulation, an LCD interface, and Blynk IoT
to demonstrate battery monitoring and fault-management behaviour.

## Screenshot Categories

| Screenshot | Purpose |
|---|---|
| Normal Battery Operation | Demonstrates normal simulated operation |
| Cell Voltage Imbalance | Shows differences between simulated cell voltages |
| Fault Detection and FAILSAFE | Demonstrates the configured fault response |
| Recovery to Normal State | Shows the demonstrated recovery behaviour |
| LCD Display | Documents the local display interface |
| Blynk Live Dashboard | Shows remote monitoring information |
| Blynk Dashboard Overview | Documents the saved dashboard overview |
| Wi-Fi Disconnection | Provides evidence associated with connectivity testing |

## Important Notes

- The PNG screenshots are currently stored in the repository root.
- The main repository README links to these screenshots.
- These screenshots represent simulation evidence, not validation on a real battery pack.
- Only behaviour demonstrated by the available evidence should be described as verified.
